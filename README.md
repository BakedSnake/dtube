# DTUBE :: Dmenu wrapper for playing/streaming videos

**DTUBE** is wrapper that uses `yt-dlp` & `mpv` to stream or download *Youtube* videos or *Twitch* streams.

## Dependencies

- dmenu
- xclip
- mpv
- yt-dlp

## Features

- Search *Youtube* videos
- Play / Stream videos
- Download videos
- Get video url
